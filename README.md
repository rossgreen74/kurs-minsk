# Курс наличной валюты в обменниках Минска

Страница показывает курсы покупки и продажи наличных USD, EUR и RUB по обменным пунктам
Минска: где сейчас дешевле, сколько это в рублях на нужную сумму и какая точка с курсом
лучше есть поблизости.

Данные снимает расписание GitHub Actions с [myfin.by](https://myfin.by/currency/minsk)
и кладёт в `data.json`; страница читает этот файл и показывает, сколько минут назад он снят.

- `build.py` — сбор и разбор таблицы, проверка данных на вменяемость
- `.github/workflows/` — расписание обновления

Курс в приложении — то, что банк опубликовал несколько минут назад. Обязательным
и окончательным остаётся курс на табло в обменном пункте.
